# Making Dough: Grandma's Bakeria

Socratica Baking Buildathon project: phone ordering + a dashboard for Grandma's bakery.

**The app lives in [`bakeria-mern/bakeria`](bakeria-mern/bakeria/README.md). Start there for build/run/demo instructions.**

```bash
cd bakeria-mern/bakeria
cp .env.example .env          # set MONGO_URI + GRANDMA_PIN
npm run build && npm start    # http://localhost:5050  (dashboard: /grandma)
```

- `Socratica Baking_Hackathon/`: menu info cards (item photos, ingredients, nutrition, allergens, 5 languages); source for the app's menu
- `archive/`: early single-file HTML prototypes, kept for reference only
